## שלב 2: ממשק ראשוני
- 2.1 שלד monorepo: ‏Vite, ‏TS, ‏ESLint, ‏Vitest, ו-Capacitor Android.
- 2.2 Design system: טוקנים (צבע, טיפוגרפיה, ריווח), Dark/Light, ‏RTL, ‏i18n (עברית ואנגלית), אייקונים (Lucide), ורכיבים (כרטיס, כפתור, Sheet תחתון, Slider, Toast).
- 2.3 ניווט: Bottom tab bar ביד אחת (בית, ספרייה, עורך, מדפסת, הגדרות). תמיכה במצב אנכי ואופקי.
- 2.4 Dashboard: הפריסה המלאה. כל עוד אין חיבור, הכרטיסים מציגים "לא מחובר" ולא ערכים מומצאים.
- 2.5 Viewer: משטח A1 בגודל 256×256 עם גריד, מצלמה במגע (סיבוב, זום, הזזה).
- 2.6 GitHub Actions: בדיקות ו-APK להורדה.
- **קבלה:** ה-APK מותקן ב-S25. מעבר בין מסכים, Dark/Light, החלפת עברית ואנגלית, ותצוגת משטח 3D חלקה.

## שלב 3: ניהול קבצים ועריכה
- 3.1 Gateway: שלד FastAPI, ‏SQLite, אימות משתמש (התקנה ראשונה וצימוד), ‏Docker.
- 3.2 העלאה: ‏STL/3MF/OBJ/STEP, בדיקת תקינות, ספרייה, תיקיות, שינוי שם, שכפול, מחיקה ופרויקטים.
- 3.3 Android: ‏Intent "פתח באמצעות" ו-Share (WhatsApp), בוחר קבצים (כולל Google Drive דרך SAF).
- 3.4 עורך: הזזה, סיבוב (X/Y/Z), ‏scale באחוזים או במ"מ עם נעילת פרופורציות, Mirror, שכפול, ריבוי מודלים, הורדה למשטח, Lay-flat, ‏Auto-arrange, ואזהרה על חריגה מגבולות המשטח.
- 3.5 Cut לפי מישור ו-Split לחלקים (manifold-3d).
- **קבלה:** קובץ מ-WhatsApp נפתח באפליקציה, נערך, נשמר כפרויקט, ונפתח מחדש בדיוק כפי שנשמר.

## שלב 4: מנוע Slicer
- 4.0 **Spike:** ‏Docker עם OrcaSlicer 2.4.2, חיתוך קוביית 20 מ"מ עם פרופיל A1 0.4. התוצאה היא `.gcode.3mf` תקין.
- 4.1 שיטוח פרופילי BBL (machine, process, filament) ופרופילי מערכת של A1.
- 4.2 תור עבודות, התקדמות ב-WebSocket, ביטול ו-timeout.
- 4.3 מסך הגדרות: איכות, מילוי, חומר, טמפרטורות, מהירויות, תמיכות (Normal/Tree, משטח בלבד או בכל מקום, צפיפות, Interface, זווית), ומתקדם (Retraction, קירור, Brim/Skirt/Raft, ‏Z-Hop, ‏Adaptive Layer Height). כל שדה ממופה למפתח אמיתי של Orca.
- 4.4 פרופילים אישיים: שמירה, ייצוא וייבוא.
- 4.5 תצוגת G-code: שכבות, Slider, שכבה בודדת או הכל, צבעים לפי סוג (קיר, מילוי, תמיכה, travel) ואנימציה.
- 4.6 הערכות: זמן, גרמים ומטרים מתוך Orca, ועלות לפי מחיר לק"ג.
- 4.7 (ב) צביעת תמיכות ידנית (paint supports ב-3MF).
- **קבלה:** מודל אמיתי נחתך עם תמיכות עץ, ותצוגת השכבות זהה למה ש-Bambu Studio מראה לאותן הגדרות.

## שלב 5: תקשורת עם המדפסת
- 5.1 `PrinterDriver` ו-`BambuA1Driver`: ‏MQTT/TLS, ‏pushall, פענוח דוחות, חיבור מחדש.
- 5.2 גילוי ב-SSDP והזנה ידנית (IP, Serial, Access Code מוצפן).
- 5.3 העלאה ב-FTPS עם התקדמות, אימות ו-retry.
- 5.4 זיהוי מצב ענן או מפתח, וזרימת הדפסה מלאה (זמינות, אישור, idempotency, אישור מהמדפסת).
- **קבלה (על המדפסת שלך):** סטטוס חי במצב ענן, העלאה ל-SD, וקוביית כיול שמודפסת מהטלפון במצב מפתח.

## שלב 6: שליטה מרחוק
- 6.1 Pause/Resume/Stop עם אישור מהמדפסת, תאורה ושגיאות HMS בעברית.
- 6.2 מצלמה חיה (פורט 6000, מועבר דרך ה-Gateway).
- 6.3 Tailscale: מדריך התקנה, ‏HTTPS (MagicDNS cert), בדיקה מרשת סלולרית.
- 6.4 התראות push (סיום הדפסה או שגיאה).
- **קבלה:** מחוץ לבית, ברשת 5G, רואים מצלמה וסטטוס ועושים השהיה.
