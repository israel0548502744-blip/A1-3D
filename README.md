# Bambu Control Studio

אפליקציית אנדרואיד להדפסה בתלת-ממד מהטלפון: פתיחת מודלים, עריכה בתלת-ממד, חיתוך לשכבות בתוך הטלפון, תצוגת שכבות, ובהמשך שליחה ושליטה במדפסת, בבית ומחוץ לבית. התחילה עם Bambu Lab A1 ותומכת ברשימת מדפסות מכל היצרנים הנפוצים.

> שם העבודה "Bambu Control Studio" יוחלף לפני מכירה (סימן מסחר של Bambu Lab). ראו `docs/LEGAL.md`.

**סטטוס:** אפליקציה אחת. `apps/web` (העורך והסלייסר) נארז בתוך `apps/android` (APK), ורץ בטלפון בלי שרת.
- עורך תלת-ממד: טעינת STL/3MF/OBJ/STEP, תצוגה על משטח ה-A1, הזזה/סיבוב/קנה-מידה/שיקוף/שכפול/סידור, אזהרת חריגה, חיתוך מודל לחלקים (manifold-3d), וייצוא STL.
- סלייסר ניסיוני בטלפון: שכבות, קירות, מילוי, הערכות (זמן/משקל/עלות) ותצוגת שכבות.
- ממשק עברית RTL בשפת העיצוב של Makeo 3D, בשחור-ירוק, מצב כהה/בהיר.
- 57 מדפסות לפי סדר פופולריות (Bambu Lab, Creality, Elegoo, Anycubic, Prusa, Qidi, Flashforge, Sovol ועוד), עם גודל משטח לכל מדפסת והוראות חיבור. ראו `docs/PRINTERS.md`.
- בדיקה משפטית ורשימת "לפני מכירה": `docs/LEGAL.md`.
- **טרם מומש:** חיבור למדפסת (שכבה נייטיבית ל-MQTT/FTP, בבית בלי שרת); שכבות עליונות/תחתונות, תמיכות, ו-`.gcode.3mf`.

### להריץ מקומית
```bash
cd apps/web && npm install && npm run dev
```
